# Digital Business Card

A personal digital business card built with React. This was my first solo React project, completed as part of [Scrimba's React course](https://scrimba.com).

## About

A single-page card with my photo, contact links, a short bio, interests, and social icons — split into separate React components.

## Features

- **Info** — profile photo, name, role, and Email / LinkedIn buttons
- **About** — short bio with Scrimba attribution
- **Interests** — personal interests section
- **Footer** — social icons (GitHub, Facebook, Instagram)

## Tech Stack

- React
- Vite
- Font Awesome (icons)
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
